# ADR-004: Static HTML packages and DOCX exports

Accepted for implementation, 2026-10-12. Scope: ART-02, CFG-01, DEL-01/02, SEC-01, UI-01/02.

Java 21 and JasperReports 7.0.3 remain pinned. The installed 7.0.3 core JAR was inspected with `javap` to verify `JRDocxExporter`, `HtmlExporter`, their configuration setters and `HtmlResourceHandler`. No new dependency is required. Official documentation describes [DOCX grid export](https://jasperreports.sourceforge.net/api/net/sf/jasperreports/engine/export/ooxml/JRDocxExporter.html), [HTML resource handlers](https://jasperreports.sourceforge.net/api/net/sf/jasperreports/export/HtmlExporterOutput.html) and [HTML configuration](https://jasperreports.sourceforge.net/api/net/sf/jasperreports/export/SimpleHtmlReportConfiguration.html). These live pages describe 7.0.8; executable tests validate the pinned 7.0.3 API and output.

DOCX is a normal `.docx` artifact with the WordprocessingML MIME type. Jasper's exporter emits a grid/table layout; it does not promise PDF-identical pagination or native Word authoring semantics. Hyperlinks are disabled and exporter settings override template hints. Tests parse generated document XML, check expected data and consumer text, and reject unexpected macros, embeddings and external relationships in the fixture. No Word/LibreOffice visual round-trip or configurable document protection is claimed.

HTML is represented by `format: HTML`, but delivered as an `application/zip` artifact ending in `.html.zip`. The compound extension is intentional: it preserves the report format while clearly indicating packaging. The archive contains `index.html` and generated resources beneath `assets/`. It is streamed as an attachment and never rendered, extracted or mounted inside the application origin. There is no report HTML preview route, iframe or `dangerouslySetInnerHTML` flow.

The trusted template's consumer text is exported as escaped text. HTML hyperlinks are disabled. A fixed header includes UTF-8, language, viewport and a restrictive CSP: no script or network default, only local/data images, inline styles and local fonts. SVG export is configured for image conversion. This is an output policy for trusted templates, not an untrusted-JRXML execution sandbox. Template authoring, external/lazy resources and arbitrary custom assets remain disabled.

A bounded in-memory resource handler accepts only simple ASCII filenames, rejects traversal, slashes, percent-encoded paths and conflicting duplicate names, and prefixes archive entries with `assets/`. It tracks references and fails packaging if referenced bytes are missing. At most 128 generated resources and 10 MiB total uncompressed content, including HTML, are allowed. The final ZIP is also bounded at 10 MiB. ZIP entries are ordinary files with stable timestamps; no filesystem extraction, caller paths or symlinks are involved. A test JRXML with a generated bitmap verifies that the HTML reference resolves to an actual decodable packaged image. Missing/unsafe/oversized resources fail export and participate in the existing required/optional outcome rules.

V12 extends the format and storage-key constraints without changing older migrations. Request v2 now permits up to five distinct formats and four optional formats, retaining at least one required output and the existing six-mapping limit. Maximum fan-out is 30 delivery tasks, with at most 50 MiB staged across five outputs. Existing active-job, 15-minute deadline and per-artifact limits remain in force; this is a bound, not a benchmark or capacity commitment.

Go accepts only the new `.docx` and `.html.zip` suffixes, never bare `.html`, arbitrary `.zip` or `.docm`. Both provider MIME types and signed-link filenames preserve the exact representation. Canonical task serialization and existing inbox fingerprints remain unchanged. Upgrade Go and core together before admitting these formats. Old workers cannot handle their keys; rollback must drain/preserve accepted work and use a coordinated restore or forward fix. Actual provider IAM/expiry tests remain unavailable.
